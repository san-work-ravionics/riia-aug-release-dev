Progressive Web App served from /mobileapp. Optimised for phone width. Provides: portfolio summary, data science (DS) model view, algo screen (6-tab layout added in F50), instrument GEO KPI tiles, and navigation. Communicates with the Experience Layer via the same api.js auth pattern as the desktop dashboard. Installable as a home-screen app.
